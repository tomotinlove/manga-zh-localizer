# Manga Localizer (`manga-zh-localizer` v4.4) — Always-On Constraints & Fast CLI

- **Portable Paths & Shared Config (NEVER hardcode personal paths)**:
  - All scripts auto-resolve `inbox_dir`, `out_dir`, `tmp_dir`, `browser_bin`, and `glossary_dirs` via `scripts/_common.ps1` (`CLI flags` > `MANGA_*` env vars > `config/config.local.json` > `~/.manga-zh-localizer/config.json` > portable defaults `./inbox`, `./out`, `$env:TEMP\manga-zh-localizer`).
  - Process every image at its exact native `W×H` resolution (do NOT nag for 4K unless a chat upload was downscaled to `<=1024px`).
  - Single-page output: `<out_dir>\<base>_zh.png`; multi-page works (`>= 2` pages): dedicated ordered folder `<out_dir>\<job>\01_<base>_zh.png`..`NN_` with monotonic timestamps + vertical long stitched strip `00_<job>_long_zh.png`.
- **Execution & Turn-Budget Discipline (3–4 turns total, NO wasted scripts)**:
  - Windows PowerShell 5.1+ only (zero Python/CUDA dependency); always invoke scripts with `powershell -NoProfile -ExecutionPolicy Bypass -File ...`. Keep any `.ps1` pure ASCII, read/write JSON/HTML with explicit UTF-8, and ALWAYS pass multi-image lists to `-File` as a single pipe-delimited string `"<p0>|<p1>|..."` (NEVER comma-separated or unjoined arrays).
  - Resolve `<SCRIPTS>` as `skills/manga-zh-localizer/scripts` next to `SKILL.md`.
  - **Use `batch_job.ps1` directly** instead of writing throwaway helper scripts. Only open `references/schemas.md` or `references/lessons.md` when hitting an unusual op or edge case. Cap web search to **at most 1 parallel batch** for genuinely unknown proper nouns/memes (check glossaries first).
- **Core CLI (`<SCRIPTS>`)**:
  0. **All-in-one parallel job runner (`batch_job.ps1` — USE BY DEFAULT)**:
     - Environment check: `batch_job.ps1 -Mode doctor`
     - Scan (`grid_inspect -FastPreview -PrintSummary` in parallel + `preview_sheet.jpg` + `job_manifest.json`): `batch_job.ps1 -Mode scan -Latest` (or `-Pattern "<prefix>*"` / `-Images "<p0>|<p1>"`)
     - Clean + Typeset in parallel + `diff_sheet.jpg` / `qa_sheet.jpg` / `audit_sheet.jpg` (auto-skips unchanged cleans; supports `-Pages "p1"` or `-CleanOnly`): `batch_job.ps1 -Mode build -Job <job>`
     - Ordered multi-page export + long strip (or single-page copy): `batch_job.ps1 -Mode package -Job <job>`
  1. `grid_inspect.ps1` — Grid + Chamfer auto-bubbles (`has_text`, `dark_bbox`, `bg_type`) + preview
  2. `make_sheet.ps1` — Contact sheet stitcher (split 4 pages/sheet for 5+ pages)
  3. `clean_bubbles.ps1` — `LockBits` lossless cleaner + Chamfer DT tail-immune `optical_center` + `[CleanAudit]` guards + pixel-diff heatmap
  4. `render_typeset.ps1` — `2xSS`, 24-angle circular stroke, upright `…`/`—`/`.vwave` `～`, sideways `.latin`, lock-free headless Edge/Chrome, Chamfer cavity auto-snapping + scaled auto-clearance + directional `WARN_BORDER_HITS` / `WARN_RECT_OVERLAP` audit
  5. `make_longstrip.ps1` — Ordered multi-page export with monotonic timestamps + vertical long strip
  6. `roi_composite.ps1` — Lossless AI panel ROI composite (`-AutoTrimAiMargins`, `mode:"glyph_diff"`, `polarity:"both"`; invoke AI image editing sequentially if available)
- **Zero-Defect Cleaning, Typography & Delivery Iron Rules**:
  - **Zero color blocks / smears & strict translation coverage**: NEVER stamp `solid_rect` over speedlines, screentones, gradients, tilted gridlines, patterned textures, off-white/tinted backgrounds (`RGB 244–250`), curved hair/character silhouettes, or touching any speech-bubble outline (use contour-hugging `poly_fill` with explicit `rgb`, never `sample`; erase the *entire* hand-drawn highlight oval and re-render `halo`). Never point a later op's `sample` at pixels overwritten earlier in the same `clean_plan.json`. Verify `copy_col`/`copy_row`/`copy_along_dir` anchor spans are 100% clean (split 1D gradients into 2 bands if needed); prefer `solid_rect` + exact-endpoint `draw_lines` for thin straight gridlines on flat backgrounds; keep `dx = 0` (`offset: [0, dy]`) when `patch_copy` spans a vertical panel divider. **NEVER use `translucent_anchored`/`translucent_halo` across sharp high-contrast B&W lineart + black-bg boundaries** (triggers `WARN_HARMONIC_SMEAR`; use AI panel inpainting + `roi_composite.ps1` sequentially, or crisp `poly_fill` + `patch_copy` + `draw_lines`); use `color_flood` (not `white_bubble`) on grey/tinted bubbles (`RGB <= 242`) and closed flat-color props/reaction bubbles (for white-stroked text in tinted bubbles, seed open tinted margin with `tol: 70–85`); use `copy_along_dir` for speedlines, phase-aligned `patch_copy` for HD screentones, `draw_lines` for micro border repairs; never let `interp_v`/`interp_h` touch dark borders/figures; NEVER mask dirty cleaning with overly thick white strokes. ALWAYS clean & translate props, signs, photo/UI captions, reaction bubbles, and clean/flat/1D-gradient SFX; restrict `留原字+旁注` strictly to pure atmospheric SFX over intricate artwork.
  - **Concise Chinese, vertical punctuation & line-breaks**: Target **70%–85%** of JP char count; break Japanese SOV translationese into natural oral Chinese and run a **raw-free read-through** before typesetting. In regular vertical speech bubbles: **omit internal commas `，` and terminal periods `。`**, **never start a column with `的`/`了`/`呢`/`吗`**, break semantically without splitting words, shape lines organically to the bubble, default `line_height` `1.20–1.33` / `letter_spacing` `0`. Uniform base size **`2.35%–2.5%` of page width** (`90%–115%` across regular bubbles); lock one font family per role across the chapter; true weights only (`dialogue`/`narration`: YaHei `700`; `serif`: STZhongsong `400`; `handwritten`: STKaiti `400`; `round`: YouYuan `400`; `brush`: STXingkai `400`; `scream`: SimHei `700`; never faux-bold). Retain recognized English/Latin proper nouns untranslated; annotate obscure memes with unobtrusive `※注：...` in open margins.
  - **Mandatory QA & sync gate**: Keep adjacent `layout.json` block `rect`s separated by `>= 12px`. Verify `0` `[CleanAudit]` warnings and `0` `[Audit]` warnings, and inspect full-res `_zh.png` (plus 2× `orig | clean | zh` crops for non-bubble, bubble-adjacent, gradient, AI-inpainted, or textured cleans) after EVERY final build before delivering. After ANY single-page tweak in a multi-page job, ALWAYS re-run `batch_job.ps1 -Mode package` so the long strip and monotonic timestamps stay in sync.
- **Glossaries**: User glossaries live in `~/.manga-zh-localizer/glossaries/*.json` (template at `skills/manga-zh-localizer/glossaries/_template.json`).
